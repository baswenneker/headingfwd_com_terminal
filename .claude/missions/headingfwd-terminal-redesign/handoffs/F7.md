# Handoff — Playwright-suite herschreven naar de nieuwe UI

## In één oogopslag
De volledige e2e-suite is herschreven voor de nieuwe terminal. **Alle 27 tests slagen**
(`pnpm test:e2e`, ~31s, 1 worker). Geen productcode aangeraakt — alleen tests, helpers,
fixtures en `playwright.config.ts`.

## Wat is gebouwd
- **`tests/helpers/api-mocks.ts`** herschreven naar het **AI-SDK-v6 UI-message-stream**-formaat
  (SSE met `data: {type:…}`-chunks): `createTextStream`, `createEmailToolStream`, plus
  `mockChatSuccess`/`mockChatError`/`mockRateLimitError`/`mockEmailToolSuccess`/
  `mockEmailToolRateLimit`. (Het oude `0:"…"`-formaat werkte niet meer met v6.)
- **`tests/helpers/session.ts`**: `sendCommand` (slash-command, geen wachten op een
  assistant-message), `sendAIMessage` (vrije tekst, wacht op `assistant-message` + indicator weg).
- **`tests/fixtures/command-outputs.ts`** en **`mock-responses.ts`** afgestemd op de exacte copy
  uit `terminal-commands.ts`, met unieke substrings om Playwright strict-mode dubbele matches te
  vermijden (de specialities staan zowel in de intro als in de `/services`-feed).
- **Specs** herschreven: commands (20 tests: /help, /about, /services, /work, /stack, /contact,
  /clear, /cls, /whoami, /ls, history-recall, meerdere na elkaar, geen captcha) + 2 mobiele
  375px-tests; chat-streaming (5, gemockte AI-stream + markdown); email-flow (2, ✓ verzonden +
  rate-limit); rate-limiting (3, leesbare fout, geen JSON, /clear ruimt op).
- **`playwright.config.ts`**: maakt de SQLite-test-DB-directory aan vóór de server start
  (`@libsql/client` maakt zelf geen parent-directories), zodat `.env.test` ongewijzigd blijft.

## Geverifieerd (orchestrator)
`pnpm test:e2e` zelf gedraaid: **27 passed (31.6s)**. Diff bevat geen `src/`-wijzigingen. Geen
mission-codes in de testbestanden.

## Aandachtspunten (voor F8 / opruimen)
- Ongebruikte `tests/helpers/assertions.ts` en `tests/fixtures/test-sessions.ts` /
  `error-messages.ts` zijn nog niet verwijderd (onschadelijk; opruimen hoort bij F8).
- De `console.error("[AI Chat Error]", err.message)` in `terminal.tsx` logt tijdens de
  rate-limit-tests de rauwe `err.message` naar de console — dit is een debug-log, niet
  zichtbaar voor de bezoeker (de UI toont de nette melding). Geen bug.
- `SKIP_LIVE_TESTS` in `.env.test` heeft geen effect meer (alles is gemockt).
